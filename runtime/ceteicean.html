CETEIcean Rendering Path (a subset, in the browser)

Pipeline: ODD → generator → tei-ceteicean-behaviours.js → CETEIcean (browser) → HTML

CETEIcean registers TEI elements as tei- custom elements; the ODD-derived behaviours reshape them into the HTML the other renderers emit, with the same classes, so the shared edition.css applies. This tier takes a subset of the Processing Model: predicates CSS can express, simple params. Click notes to expand; click corrections to toggle readings.
